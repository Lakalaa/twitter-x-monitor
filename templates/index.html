Render / Production Deployment

When deploying to Render, set these as Environment Variables in your Render service dashboard instead of using this form:

TELEGRAM_BOT_TOKEN — your bot token
TELEGRAM_CHAT_ID — your group chat ID (e.g. -1003707579699)
TWITTER_AUTH_TOKEN — your Twitter auth_token cookie
TWITTER_CT0 — your Twitter ct0 cookie (CSRF token — required!)

Render keeps them encrypted and they survive every redeploy automatically.

Telegram Bot Commands

Send these commands to your bot (@BloomEthereumn_bot) in any chat or the group:

/start
Show welcome message and all available commands
/check
Run all checks from Targets immediately — sends results to the group
/followers elonmusk
First call: scrapes ALL followers, sends first 500. Each next call sends the next 500 instantly from cache.
/following OpenAI
Same as /followers but for the accounts they follow.
/rescrape_followers username
Clear cache and force a fresh re-scrape of followers from scratch.
/rescrape_following username
Clear cache and force a fresh re-scrape of following from scratch.
/compare username
Show mutuals, followers-only, and following-only for any account.
/replies <url> [--no-admins]
Scrape all replies to a tweet — each reply shows the commenter's account and their message. Add --no-admins to skip verified/blue-tick accounts.
/mirror <source_url> <target_url> [--no-admins]
Scrape all replies from source tweet and post each one as a comment on target tweet. Add --no-admins to skip verified accounts. Rate-limited to 1 post every 8 seconds.
/replyall <url> [count] [--no-admins] [@mention] <text>
Scrapes every reply under a tweet, then replies back to each commenter using your accounts (rotating). count = how many accounts to use (default: all). --no-admins = skip verified accounts. Example: /replyall https://x.com/.../123 50 --no-admins Thanks! 🙌
/scrape <tweet_url> [--no-admins]
Step 1: Scrapes all repliers from a tweet and saves their usernames. Add --no-admins to skip verified/blue-tick accounts. Run this first, then use /tagusers whenever you're ready. Example: /scrape https://x.com/user/status/123 --no-admins
/tagusers <target_url> [count] [--no-admins]
Step 2: Tags the users saved by /scrape — 5 per reply — as replies under the target tweet. count = max users to tag. Each reply looks like: @user1 @user2 @user3 @user4 @user5. Example: /tagusers https://x.com/yourprofile/status/999 50
/tag <source_url> <target_url> [count] [--no-admins]
Shortcut: scrape + tag in one step. Both URLs in one command. Example: /tag https://x.com/src/111 https://x.com/tgt/222 50
/complaints your brand
Search complaint tweets about any topic (last 7 days)
/status
Show which accounts are tracked + last/next check times
/help
Show all commands

How Results Look in Telegram

Followers/Following list — sent in batches of 20. Each user shows their username, display name, follower count, verified badge, and profile link (https://x.com/username)


New follower alerts — sent immediately at the top when someone new appears since the last check. Shows their full profile info.


Complaint tweets — one message per complaint tweet. Shows username + profile link, tweet text, likes/retweets/replies, and tweet link.
